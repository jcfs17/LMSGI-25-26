# LMSGI 25/26 — Ejercicios de HTML y CSS

Juan Carlos Fosela Suela

Este repositorio contiene varios ejercicios prácticos realizados para la asignatura de Lenguajes de Marcas (LMSGI).  
Cada ejercicio está organizado en su propia carpeta e incluye un ejemplo funcional creado por mí.

## Contenidos

- **Botonera**  
  Ejemplo de una interfaz con botones estilizados mediante CSS.

- **Carrusel**  
  Carrusel básico de imágenes usando HTML, CSS y JavaScript.

- **Menú desplegable**  
  Menú de navegación con submenús visibles al pasar el ratón.

- **Protoweb**  
  Estructura simple de una página web con cabecera, navegación, contenido y pie.

- **Tabla + Formulario**  
  Página con una tabla de datos y un formulario básico.

---

Cada carpeta contiene su propio `index.html` con el ejercicio correspondiente.
